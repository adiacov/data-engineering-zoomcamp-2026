# Data Engineering Zoomcamp — Learning Repository

## Summary

This repository contains my hands-on work from the **Data Engineering Zoomcamp** by DataTalksClub — a well-known, practice-oriented program focused on building **end-to-end data engineering systems** using modern tools and industry patterns.

Program reference:
[https://github.com/DataTalksClub/data-engineering-zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp)

## Purpose

The goal of this repository is to demonstrate:

* Practical data engineering skills
* Ability to design, build, and reason about data pipelines
* Familiarity with real-world data stacks and workflows
* Clean, structured, and reproducible engineering work

## What This Repository Shows

* End-to-end data pipelines (ingestion → storage → transformation → analytics)
* Batch and streaming data processing
* Data modeling and analytics engineering concepts
* Cloud and infrastructure fundamentals
* Production-style tooling, configuration, and documentation

## Technologies & Concepts

Depending on the module, this repository includes work with:

* Python, SQL
* Docker
* Workflow orchestration
* Data lakes and data warehouses
* Spark / distributed processing
* dbt and analytics engineering
* Cloud platforms (e.g., GCP / AWS)
* Infrastructure-as-code

## Structure

* Each Zoomcamp module has a dedicated directory
* Code, configuration, and notes are kept close together
* Emphasis on readability, correctness, and reproducibility

## Learning Approach

* Focus on fundamentals and correctness over shortcuts
* Incremental, module-by-module progression
* Explicit documentation of assumptions and design decisions

## Notes for Reviewers

This repository reflects **intentional learning and implementation choices**, not copy-paste solutions.
Where relevant, trade-offs, limitations, and improvements are documented.
